# AI Customer Support Agent

An AI-powered customer support application built with **Python, Flask, PostgreSQL, React, and Gemini**.

The system uses **Generative AI and tool calling** to automate customer-support workflows such as customer lookup, warranty verification, and service-ticket creation.

## Key Features

- Gemini-powered AI customer support assistant
- AI function/tool calling
- Customer lookup from PostgreSQL
- Product warranty verification
- Service-ticket creation
- Multi-step AI workflows
- JWT authentication and role-based access
- React + Vite frontend
- Flask REST APIs
- PostgreSQL database
- Swagger/OpenAPI documentation
- Pytest-based testing

## Tech Stack

**AI:** Gemini, Generative AI, Tool Calling  
**Backend:** Python, Flask, REST API  
**Database:** PostgreSQL  
**Frontend:** React, Vite, JavaScript  
**Security:** JWT, Bcrypt  
**Testing:** Pytest  
**Documentation:** Swagger/OpenAPI
